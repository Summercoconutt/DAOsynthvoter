# Anonymous LNCS paper starter

This is a generic PUBLIC template, NOT the actual unpublished research manuscript.
Copy into a separately controlled PRIVATE repository or private Overleaf project before writing claims, adding results or adding author information.

Start with Springer's official LNCS Overleaf template:
https://www.overleaf.com/latex/templates/springer-lecture-notes-in-computer-science/kzwwpvhwnvfj

Use the official template's llncs.cls and other dependencies. Place main.tex and verified bibliography entries in references.bib. Replace every TODO using defensible experimental evidence. Keep the submission anonymous and check the CAAW page limits and PDF fonts before submission.
